Product: PlotKit
Version: 1.0.0


## Description
PlotKit is a Java library that provides a framework for building flexible plotting capablity into an application.


## Dependencies
The PlotKit library has the following dependencies:

- Java 17
- Glum: 2.1.0
- Guava: 18.0+
- MigLayout: 3.7.2

Note the following:

- In theory PlotKit should work with later versions of the above listed software, however these are the ones utilized / tested during development.
